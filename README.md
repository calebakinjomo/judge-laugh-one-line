Entry for the make.fun competition [Make the Judge Laugh in One Line](https://make.fun/bounty/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21).

## The line

> I bought a self-help book and it filed a restraining order.

## How it works

`main.py` writes that one line (plus a trailing newline) to `/output/entry.txt`,
deterministically. No network, no randomness, no time dependence.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
